# 🌿 EFT-Ψ / EFT-END：用于生成渐进披露式情绪聚焦心理健康支持对话的多智能体框架

[中文](README.md) | [English](README_en.md)

> 🧠 **EFT-Ψ** 是一种情绪聚焦疗法（Emotion-Focused Therapy, EFT）取向的知识驱动多智能体心理支持对话生成框架，通过结构化心理知识、来访者过程画像与信息不对称交互，生成具有渐进披露和情绪探索过程的多轮心理支持对话。

**论文题目：**
*EFT-Ψ: A Multi-Agent Framework for Generating Emotion-Focused Mental Health Support Dialogues with Progressive Disclosure*

**数据集：** EFT-END

**模型：** EFT-Chat

---

## 🌟 项目简介

欢迎来到 **EFT-END** 项目仓库。

现有心理健康支持对话数据构建方法仍存在一些局限。例如，基于大语言模型模拟的来访者往往具有较高的开放性和自我觉察水平，容易较早、较清晰地说明自身经历、情绪来源和心理问题，使对话呈现出过度配合的特征；与此同时，部分生成方法会向咨询师提供较完整的个案背景或心理状态，使其具有近似“全知”的先验视角。

此外，现有方法对情绪体验和咨询过程渐进性的建模仍相对不足，较少体现真实心理支持过程中常见的**模糊表达、渐进披露和保护性抗阻**。

针对上述问题，我们提出 **EFT-Ψ**，一种 EFT 取向的知识驱动多智能体心理支持对话生成框架。

EFT-Ψ 主要通过以下机制实现多轮心理支持对话生成：

* 🧩 基于**情绪—需要图谱（Emotion–Need Diagram, END）**组织结构化心理知识
* 👤 通过**情绪觉察水平和保护性抗阻画像**刻画来访者过程差异
* 🔐 显式建模来访者与咨询师之间的**信息不对称**
* 🌊 实现潜在心理知识的**受控显现与渐进披露**
* 🧠 基于已显现的对话证据进行**工作性 END 重建**
* 🤖 通过四类智能体逐轮协作完成来访者表达、END 重建、EFT 取向回应和 END 披露调节

基于 EFT-Ψ，我们构建中文多轮心理健康支持对话数据集 **EFT-END**，并进一步基于该数据集训练心理健康支持对话模型 **EFT-Chat**。

## 🧠 EFT-Ψ 框架

EFT-Ψ 面向由心理求助文本生成多轮心理支持对话的任务，通过结构化心理知识、来访者过程建模与多智能体协作，实现**信息不对称条件下的渐进式对话生成**。

整体框架包括两个相互衔接的阶段：

### 阶段 I：隐藏个案知识初始化

针对每个原始心理求助文本，系统构建隐藏个案表示，包括：

* **完整隐藏 END**：表示与当前困扰、情绪体验、需要和保护性反应相关的结构化心理知识；
* **来访者过程画像**：刻画来访者的情绪觉察水平和保护性抗阻，并调节后续表达清晰度、披露节奏和保护性反应方式。

上述信息共同构成隐藏个案知识，并作为后续多轮交互的基础。

### 阶段 II：END 引导的多智能体交互

该阶段在信息不对称条件下进行。

针对每个个案，系统维护三类知识状态：

* 🔒 **完整隐藏 END**
* 👤 **来访者可见 END**
* 🧠 **咨询师侧工作性 END**

完整隐藏 END 对咨询师侧不可见；来访者仅依据当前已经开放的知识生成表达；咨询师则只能根据可观察对话逐步形成工作性 END。

由此，EFT-Ψ 将多轮对话建模为：

> **潜在个案知识的受控显现 → 来访者逐步表达 → 对话证据逐步形成 → 咨询师侧动态重建**

## 🧩 情绪—需要图谱（END）

**情绪—需要图谱（Emotion–Need Diagram, END）** 用于按照 EFT 的情绪加工逻辑组织结构化心理知识。

END 包含七类知识字段：

### 当前现实困扰（Presenting Context）

记录本次求助涉及的主要事件、关系情境及现实影响，作为后续心理内容展开的事实锚点。

### 表层叙事（Surface Narrative）

记录来访者对当前困扰的直接解释、自我归因、关系判断或担忧，保留尚未进一步探索时的理解方式。

### 案例材料线索（Case Material Cues）

保存可在后续对话中逐步披露的事件细节、互动片段、行为反应、未表达内容及关系线索，为多轮探索提供具体材料。

### 继发情绪（Secondary Emotions）

表示当前较容易觉察和表达的情绪状态，作为进一步情绪辨识与深化的起点。

### 原发情绪（Primary Emotion）

表示可能的原发情绪方向，并保持为可验证、可修正的工作性假设，而非对来访者心理状态的确定判断。

### 未满足需要（Unmet Needs）

表示当前困扰中可能涉及的理解、安全、尊重、回应或边界等需要，为后续情绪与需要探索提供方向。

### 保护性反应（Protective Response）

表示来访者应对痛苦和关系风险的保护方式，并用于建模其披露节奏、抗阻表现与互动反应。

> **说明：** END 不被视为临床诊断或真实个案概念化，而是用于约束对话内容一致性、信息边界和情绪加工方向的工作性结构化心理知识表示。

## 💭 EFT 情绪加工过程

EFT-Ψ 将咨询过程概括为三个相互衔接的**情绪加工目标**，并进一步映射为六类可执行的咨询功能。

### 1. 增强情绪觉察

* **F1：身体与当下感受觉察**
* **F2：情绪语言化**

引导来访者从事件叙述或模糊感受回到具体情境中的身体与心理反应，并通过适度的语言支架，使模糊感受逐步转化为可体验和可表达的情绪。

### 2. 加强情绪辨识

* **F3：情绪类型辨识与推进判断**
* **F4：情绪阻断与保护过程探索**
* **F5：内在需要探索**

围绕当前情境和情绪变化过程，辨识情绪体验及其继发性反应，探索可能中断情绪体验的保护方式，并进一步识别其中可能涉及的内在需要。

### 3. 促进情绪转化

* **F6：适应性情绪整合与叙事转化**

帮助来访者在接触原有痛苦情绪的基础上，逐步整合新出现的适应性情绪资源，并形成更加温和、准确的自我理解。

> 三个情绪加工目标与六类咨询功能构成 EFT-Ψ 的咨询过程组织逻辑，**而非固定的线性阶段**。实际交互中，系统会根据当前可观察对话和工作性 END 动态确定本轮主要工作点。

## 👤 来访者过程画像

EFT-Ψ 将来访者过程特征组织为两个维度：

### 情绪觉察水平

设置三个等级：

* **低（Low）**
* **中（Medium）**
* **高（High）**

低觉察来访者更多依赖事件、身体反应或模糊不适表达体验；中等觉察能够表达部分情绪，但仍可能在感受与自我评估之间摇摆；高觉察则能够较清楚地识别和表达自身体验。

### 保护性抗阻

保护性抗阻设置两个水平：

* **低（Low）**
* **中等（Moderate）**

并包括五类保护性抗阻方式：

* **有限披露（Minimal Disclosure）**
* **情绪回避（Emotional Avoidance）**
* **防御性重构（Defensive Reframing）**
* **自我保护性贬低（Self-Protective Devaluation）**
* **无望退缩（Hopeless Withdrawal）**

保护性抗阻描述来访者面对脆弱体验时可能出现的**过程性自我保护**，而非对咨询关系的敌意或固定拒绝。

过程画像仅调节：

* 情绪表达清晰度
* 披露节奏
* 保护性反应方式

而不会改变 END 中的个案事实。

## 🤖 多智能体协作

EFT-Ψ 通过 Client、Reconstruction、Counselor 和 Mediator 四个智能体逐轮生成对话。

### 👤 来访者模拟智能体（Client Agent）

Client Agent 根据：

* 上一轮来访者可见 END
* 对话历史
* 来访者过程画像
* 轮次信息

生成来访者话语。

Client Agent 将当前允许访问的结构化知识转化为自然表达，而非直接复述 END 字段。尚未开放的 END 内容即使被咨询师推测，也不能由来访者直接、完整地确认。

### 🧠 END 重建智能体（Reconstruction Agent）

Reconstruction Agent 仅依据**可观察对话**周期性形成工作性 END。

工作性 END 包含：

* 当前现实困扰
* 表层叙事
* 继发情绪
* 原发情绪
* 未满足需要
* 保护性反应

案例材料线索不单独重建，具体事件与互动材料继续保留在对话历史中作为证据。

重建优先依据来访者主动表达及后续修正的内容，咨询师单方面提出而未获得来访者支持的解释不作为确定事实。

### 💬 EFT 咨询师智能体（Counselor Agent）

Counselor Agent 联合使用当前可观察对话和工作性 END 生成 EFT 取向回应。

系统根据三个情绪加工目标及六类咨询功能，动态确定本轮主要工作点。

回应优先锚定来访者已经表达的具体材料，并采用温和、试探的方式推进，避免：

* 诊断式判断
* 直接认知纠正
* 过早给出行动建议

### 🌊 END 披露调节智能体（Mediator Agent）

Mediator Agent 根据：

* 隐藏 END
* 来访者可见 END
* 完整对话历史
* 来访者过程画像
* 轮次信息

生成 END 披露决策。

系统分别控制：

* 表层叙事
* 下一条案例材料线索
* 至多一个深层 END 节点

的开放。

隐藏 END 仅规定**“可以开放什么”**，而不作为判断**“何时开放”**的证据。

深层节点的开放主要依据当前对话中已经显现的情绪、保护性反应与需要线索。咨询师单方面的推测不能直接触发披露。

Mediator 不接收工作性 END，以避免咨询师假设经披露机制反向进入来访者表达并形成自我确认。

## 🌊 渐进披露与信息不对称

EFT-Ψ 显式区分不同角色在互动过程中能够访问的心理知识：

```text
完整隐藏 END
      │
      │ 受控显现
      ▼
来访者可见 END
      │
      │ 来访者表达
      ▼
可观察对话
      │
      │ 基于对话证据动态重建
      ▼
咨询师侧工作性 END
```

来访者仅依据当前开放的信息生成表达，心理内容随交互逐步披露；咨询师无法直接访问隐藏心理知识，而只能依据可观察对话周期性重建工作性 END。

由此形成潜在心理知识**逐步显现、被观察和重新理解**的多轮交互过程。

## 📊 EFT-END 质量评估

本文从 **END 机制**和**多轮对话质量**两个层面进行评估。

### END 机制评估

包括三个任务：

* **END 到对话表达**
* **基于对话的 END 重建**
* **END 结构一致性**

其中：

**END 到对话表达**考察隐藏 END 中的主要心理信息能否在多轮对话中得到自然表达。

**基于对话的 END 重建**考察咨询师侧工作性 END 能否依据已经显现的对话证据形成合理的工作性心理理解，并避免引入缺乏依据的信息。

**END 结构一致性**考察信息不对称条件下工作性 END 与隐藏 END 在主要心理方向上的一致程度。

### 多轮对话质量评估

#### 来访者侧

* **真实性与渐进披露**
* **情绪体验与加工深度**
* **自我探索深度**

#### 咨询师侧

* **共情性**
* **积极倾听**
* **问题理解与澄清**
* **帮助性**

专业人工评估结果显示，EFT-END 的咨询师侧平均得分为 **4.44 / 5**，高于：

* PsyDT：**3.82**
* SimPsyDial：**3.37**

其中，EFT-END 的：

* **积极倾听：4.77**
* **问题理解与澄清：4.78**

## 🤗 EFT-Chat

为进一步评估基于 EFT-END 训练模型的性能，我们选取 **Qwen2.5-7B-Instruct** 作为主干模型，并采用**低秩适配（Low-Rank Adaptation, LoRA）**进行监督微调，得到心理健康支持对话模型：

> **EFT-Chat**

实验中，EFT-Chat 与三类模型进行比较：

* 闭源通用大语言模型
* 开源通用大语言模型
* 心理领域专用模型

### 自动评估

EFT-Chat 在 EFT-END 测试集的全部自动评估指标上均取得最佳结果。

### 专业人工评估

EFT-Chat 在四个心理支持维度上的得分为：

| 评估维度    | EFT-Chat |
| ------- | -------: |
| 共情性     | **4.23** |
| 积极倾听    | **4.75** |
| 问题理解与澄清 | **4.59** |
| 帮助性     | **3.62** |

其中，EFT-Chat 的**共情性得分在所有模型中最高**；在积极倾听、问题理解与澄清等核心维度上，与部分前沿闭源模型无显著差异。

### 两两比较

在 GPT-5.6 Sol 作为评估模型的条件下，EFT-Chat 相较四个心理领域专用基线模型取得：

* SoulChat2.0：**78.67%**
* SimPsyBot：**84.67%**
* Crispers-7B：**94.67%**
* PsyDial-Pi4：**98.00%**

的胜率。

> 由于两两比较所使用的评估上下文来源于 EFT-END 测试集，上述结果主要反映 EFT-Chat 在目标咨询场景中的**域内适配能力**，不宜直接外推至其他心理咨询取向或开放域心理支持场景。
