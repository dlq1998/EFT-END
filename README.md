## 🧩 简介

高质量、多轮且具有过程真实性的心理支持对话数据，是构建心理健康支持对话系统的重要基础。然而，现有基于大语言模型的数据构建方法仍存在一些局限：模拟来访者往往具有较高的开放性与自我觉察水平，容易过早、过于清晰地表达自身经历与心理问题；部分方法向咨询师提供较完整的个案背景或心理状态，使其具有近似“全知”的先验视角；同时，对情绪体验及咨询过程渐进性的建模仍相对不足。

针对上述问题，我们提出 **EFT-Ψ**，一种情绪聚焦疗法（Emotion-Focused Therapy, EFT）取向的知识驱动多智能体心理支持对话生成框架。

EFT-Ψ 通过**结构化心理知识、来访者过程画像与信息不对称交互**，生成具有渐进披露和情绪探索过程的多轮心理支持对话。框架以**情绪—需要图谱（Emotion–Need Diagram, END）**组织心理知识，并通过来访者模拟、END 重建、EFT 咨询和 END 披露调节四类智能体逐轮协作，实现潜在心理知识的受控显现、咨询师侧重建与 EFT 取向情绪加工。

基于 EFT-Ψ，我们进一步构建：

* 📚 **EFT-END**：中文多轮心理健康支持对话数据集，共包含 **9,523 段对话和 238,062 条话语**；
* 🤗 **EFT-Chat**：基于 EFT-END 对 **Qwen2.5-7B-Instruct** 进行领域微调得到的心理健康支持对话模型；
* 🔬 **END 机制与多轮对话质量评价体系**：用于评价心理知识的渐进表达、咨询师侧重建以及来访者与咨询师两侧的多轮互动质量。

三者共同形成：

> **EFT-Ψ → EFT-END → EFT-Chat**

## 🧠 EFT-Ψ｜知识驱动多智能体对话生成框架

EFT-Ψ 面向由心理求助文本生成多轮心理支持对话的任务，通过结构化心理知识、来访者过程建模与多智能体协作，实现**信息不对称条件下的渐进式对话生成**。

整体框架包含两个相互衔接的阶段。

### 阶段 I：隐藏个案知识初始化

针对每条原始心理求助文本，系统构建隐藏个案知识，包括：

**完整隐藏 END**
用于表示与当前困扰、情绪体验、需要和保护性反应相关的结构化心理知识。

**来访者过程画像**
用于刻画来访者的情绪觉察水平和保护性抗阻，并调节后续表达清晰度、披露节奏和保护性反应方式。

### 阶段 II：END 引导的多智能体交互

在多轮交互过程中，EFT-Ψ 区分三类知识状态：

| 知识状态            | 含义                         |
| --------------- | -------------------------- |
| **完整隐藏 END**    | 与当前个案相关的完整潜在心理知识           |
| **来访者可见 END**   | 当前已经允许来访者智能体访问和表达的心理知识     |
| **咨询师侧工作性 END** | 咨询师根据已经出现的对话证据逐步形成的工作性心理理解 |

完整隐藏 END 对咨询师不可见；来访者仅依据当前已经开放的知识生成表达；咨询师只能根据**可观察对话**逐步形成工作性 END。

因此，整个交互过程可以概括为：

```text
完整隐藏 END
      │
      │ 受控显现
      ▼
来访者可见 END
      │
      │ 自然表达
      ▼
可观察对话
      │
      │ 基于对话证据重建
      ▼
咨询师侧工作性 END
```

这使潜在心理知识在多轮交互中逐步**显现、被观察和重新理解**。

## 🧩 END｜情绪—需要图谱

**情绪—需要图谱（Emotion–Need Diagram, END）** 是 EFT-Ψ 中用于组织结构化心理知识的核心表示。

END 按照 EFT 的情绪加工逻辑组织现实困扰、情绪体验、需要与保护性反应，共包含七类知识字段：

| END 字段                         | 说明                                      |
| ------------------------------ | --------------------------------------- |
| **当前现实困扰（Presenting Context）** | 记录本次求助涉及的主要事件、关系情境及现实影响，作为后续心理内容展开的事实锚点 |
| **表层叙事（Surface Narrative）**    | 记录来访者对当前困扰的直接解释、自我归因、关系判断或担忧            |
| **案例材料线索（Case Material Cues）** | 保存可在后续对话中逐步披露的事件细节、互动片段、行为反应及关系线索       |
| **继发情绪（Secondary Emotions）**   | 表示当前较容易觉察和表达的情绪状态，作为进一步情绪辨识与深化的起点       |
| **原发情绪（Primary Emotion）**      | 表示可能的原发情绪方向，并作为可验证、可修正的工作性假设            |
| **未满足需要（Unmet Needs）**         | 表示当前困扰中可能涉及的理解、安全、尊重、回应、边界等心理或关系需要      |
| **保护性反应（Protective Response）** | 表示来访者应对痛苦与关系风险时可能采取的回避、自责、淡化、理性化等保护方式   |

> **说明：** END 不被视为临床诊断或真实个案概念化，而是用于约束对话内容一致性、信息边界和情绪加工方向的**工作性结构化心理知识表示**。

## 💭 EFT｜情绪加工过程

EFT-Ψ 将咨询过程概括为三个相互衔接的**情绪加工目标**，并进一步操作化为六类可执行咨询功能。

| 情绪加工目标     | 咨询功能                                    |
| ---------- | --------------------------------------- |
| **增强情绪觉察** | F1 身体与当下感受觉察；F2 情绪语言化                   |
| **加强情绪辨识** | F3 情绪类型辨识与推进判断；F4 情绪阻断与保护过程探索；F5 内在需要探索 |
| **促进情绪转化** | F6 适应性情绪整合与叙事转化                         |

三个情绪加工目标并非固定的线性阶段。实际交互中，Counselor Agent 根据当前可观察对话和工作性 END 动态确定本轮主要工作点，每轮原则上仅围绕一个主要工作点进行有限推进，而不机械执行 F1–F6 的固定顺序。

## 👤 来访者过程画像

除 END 外，EFT-Ψ 进一步引入来访者过程画像，用于刻画不同来访者在**情绪觉察与保护性抗阻**方面的差异。

### 情绪觉察水平

| 水平            | 预设比例 | 主要特点                      |
| ------------- | ---: | ------------------------- |
| **低（Low）**    |  40% | 更多依赖事件、身体反应或模糊不适表达体验      |
| **中（Medium）** |  40% | 能够表达部分情绪，但仍可能在感受与自我评估之间摇摆 |
| **高（High）**   |  20% | 能够较清楚地识别和表达自身体验           |

### 保护性抗阻水平

| 水平               | 预设比例 |
| ---------------- | ---: |
| **低（Low）**       |  70% |
| **中等（Moderate）** |  30% |

> EFT-END **未设置 High 保护性抗阻条件**。

### 保护性抗阻类型

| 类型                                       | 预设比例 |
| ---------------------------------------- | ---: |
| **有限披露（Minimal Disclosure）**             |  15% |
| **情绪回避（Emotional Avoidance）**            |  30% |
| **防御性重构（Defensive Reframing）**           |  30% |
| **自我保护性贬低（Self-Protective Devaluation）** |  20% |
| **无望退缩（Hopeless Withdrawal）**            |   5% |

保护性抗阻描述来访者面对脆弱体验时可能出现的**过程性自我保护**，而非对咨询关系的敌意或固定拒绝。

来访者过程画像仅调节**情绪表达清晰度、披露节奏和保护性反应方式**，不会改变 END 中已经确定的个案事实。

## 🤖 多智能体协作

EFT-Ψ 通过四类智能体逐轮生成对话：

### 👤 Client Agent｜来访者模拟智能体

根据来访者可见 END、对话历史、过程画像和轮次信息生成自然的来访者话语。

Client Agent 仅能够使用当前已经开放的 END 信息，不得直接表达尚未开放的心理知识。每轮优先回应咨询师上一轮的一个核心点，并有限推进新的信息或情绪内容。

### 🧠 Reconstruction Agent｜END 重建智能体

仅依据完整的**可观察对话历史**周期性形成咨询师侧工作性 END。

重建结果是随对话逐步更新的工作性理解，而不是确定性的个案事实。来访者主动表达、补充、修正或反复出现的内容具有更高证据权重；仅由咨询师提出、但未获得来访者支持的解释不能作为确定信息写入。

### 💬 Counselor Agent｜EFT 咨询师智能体

综合可观察对话与当前工作性 END，动态选择适合本轮的 EFT 工作点并生成咨询师回应。

回复优先锚定来访者已经表达的具体经验，并采用专业、自然、温和且试探性的方式推进，避免诊断式判断、直接认知纠正和过早给出行动建议。

### 🌊 Mediator Agent｜END 披露调节智能体

根据隐藏 END、来访者可见 END、完整对话历史、过程画像和轮次信息控制新的心理知识何时开放。

Mediator Agent 通过三个相互独立的通道进行披露：

* **表层叙事通道**
* **案例材料线索通道**
* **深层 END 通道**

每轮最多新增一条案例材料线索和一个深层 END 节点。

隐藏 END 只规定**“可以开放什么”**，并不能单独决定**“什么时候开放”**。深层心理知识必须获得当前对话证据支持后才能开放。

Mediator Agent 不接收咨询师侧工作性 END，以避免咨询师假设通过披露机制反向进入来访者表达并形成自我确认。

## ⚙️ EFT-END｜数据生成配置

在 EFT-END 的大规模生成过程中，我们根据不同智能体的任务特点和计算成本采用**异构模型配置**。

| 生成模块                 | 使用模型              |
| -------------------- | ----------------- |
| 完整隐藏 END 构建          | **GPT-5.6 Terra** |
| 来访者过程画像构建            | **GPT-5.6 Terra** |
| Client Agent         | **GPT-5.6 Terra** |
| Counselor Agent      | **GPT-5.6 Terra** |
| Reconstruction Agent | **GPT-5.6 Luna**  |
| Mediator Agent       | **GPT-5.6 Luna**  |

其中，Client Agent 与 Counselor Agent 直接负责自然语言对话生成；Reconstruction Agent 与 Mediator Agent 主要承担结构化 END 重建与披露决策任务。

EFT-END 的生成模型与后续 EFT-Chat 使用的 **Qwen2.5-7B-Instruct** 基础模型相互独立，以避免直接使用待微调模型自身生成训练对话。

## 🔬 EFT-END｜质量评价

EFT-END 从 **END 机制有效性**和**多轮对话质量**两个层面进行评价。

### END 机制评价

包含三个任务：

| 任务               | 评价目标                          |
| ---------------- | ----------------------------- |
| **END 到对话的表达**   | 隐藏 END 中的心理知识能否在多轮对话中自然表达     |
| **基于对话的 END 重建** | 工作性 END 能否根据已经显现的对话证据合理形成     |
| **END 结构一致性**    | 工作性 END 与隐藏 END 在主要心理方向上的一致程度 |

主要结果如下：

| 任务           | GPT-5.6 Sol | Claude Opus 4.8 |
| ------------ | ----------: | --------------: |
| END 到对话的表达   |    **4.69** |        **4.66** |
| 基于对话的 END 重建 |    **4.60** |        **4.54** |
| END 结构一致性    |    **4.01** |        **3.84** |

## 📈 EFT-Chat｜模型评估结果

EFT-Chat 分别与闭源通用大语言模型、开源通用大语言模型以及心理领域专用模型进行比较。

### 自动评估

EFT-Chat 在 EFT-END 测试集上的全部自动评价指标均取得最佳结果：

| Model        |   ROUGE-1 |   ROUGE-2 |   ROUGE-L |    BLEU-4 | BERTScore |
| ------------ | --------: | --------: | --------: | --------: | --------: |
| Qwen2.5-7B   |     30.60 |      6.22 |     21.74 |      6.93 |     65.97 |
| **EFT-Chat** | **44.62** | **16.66** | **34.09** | **18.13** | **72.58** |

### 专业人工评价

| Model        |      共情性 |     积极倾听 |  问题理解与澄清 |      帮助性 |
| ------------ | -------: | -------: | -------: | -------: |
| Qwen2.5-7B   |     2.81 |     2.47 |     2.94 |     2.67 |
| **EFT-Chat** | **4.23** | **4.75** | **4.59** | **3.62** |

EFT-Chat 的**共情性得分为 4.23，在所有比较模型中最高**；积极倾听得分为 4.75，与 GPT-5.6 Terra 的 4.81 无显著差异；问题理解与澄清得分为 4.59，与 GPT-5.6 Terra 和 Claude Opus 4.8 均无显著差异。

| ----------- | ----------: |
| SoulChat2.0 |  **78.67%** |

## ⚠️ 使用限制声明

* **研究用途**：EFT-Ψ、EFT-END 与 EFT-Chat 主要用于科研、教学及人工智能辅助心理健康支持研究。
* **能力范围**：EFT-Chat 主要针对情绪聚焦心理健康支持对话进行领域微调，其能力受到基础模型、训练数据和生成配置等因素影响。
* **非临床用途**：本项目定位于非临床心理健康支持研究，不构成心理诊断、正式心理治疗、精神科治疗或其他医疗服务。
* **数据性质**：EFT-END 的原始心理求助场景来源于真实心理求助文本，但其中的多轮互动由大语言模型模拟生成，因此不能等同于真实心理咨询过程。
* **END 使用边界**：END 是用于组织心理知识并约束对话生成的工作性结构化表示，不应被视为临床诊断或真实个案概念化。
* **风险提示**：模型输出具有不确定性，可能出现不准确、不适当、不完整或不安全的内容，不能替代心理咨询师、临床心理学家、精神科医生或其他心理健康专业人员。
* **高风险情境**：当前框架尚未包含针对自伤、自杀等高风险情境的专门风险识别与专业转介机制。
* **协议与许可证**：使用本项目时，应遵守所使用基础模型、数据集、API、LlamaFactory 及其他第三方依赖的许可证、服务条款和使用政策。
* **隐私与伦理**：基于本项目开展二次开发或实际部署时，使用者应自行评估数据隐私、研究伦理、安全性与实际应用风险。

本项目目前主要用于**学术研究与技术验证**。未经充分的专业评估、安全验证和专业人员监督，不建议将其直接部署为面向真实用户的自动化心理治疗系统。
